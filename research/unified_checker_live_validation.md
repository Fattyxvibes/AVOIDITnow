# Unified Checker Live Validation

**Verified:** 14 August 2026

The live checker was tested against the imported database. Searching **Apple** returned a reviewed boycott-database match for Apple’s core computers, smartphones, and tablets, and rendered three immediate alternatives on the same page: Lenovo ThinkPad/IdeaPad PCs, ASUS ExpertBook/Zenbook PCs, and Acer Aspire/Swift PCs. The result exposed its source list and the database review date.

Searching **Example Unlisted Item** returned the distinct status **“No reviewed database match.”** The interface stated that the supplied database has no reviewed entry for the search and did **not** represent this as confirmation that the item is not boycotted. The source list remained available for the user to inspect.
